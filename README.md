# Gapper

**Bridge the gap. Unlock your potential.**

منصة ويب بتساعد طلاب علم الحاسوب وهندسة الحاسوب يعرفوا شو المهارات اللي لازم يتعلموها بكل سنة وفصل، ليش مهمة، وكيف يتدربوا عليها، وبتخليهم يتابعوا تقدمهم فيها. النسخة مبنية على ملف المشروع (Gapper Project Brief) وعلى التصاميم العشرة.

## التشغيل

بدها Node.js نسخة 22.13 أو أحدث.

أسهل طريقة على ويندوز: دبل كليك على **`تشغيل Gapper.bat`**. بينزّل المكتبات وبيبني الموقع أول مرة، وبعدين بيفتحه بالمتصفح على `http://localhost:3400`.

أو من الطرفية:

```bash
npm install
npm run dev
```

`npm run dev` وضع التطوير: أي تعديل بالواجهة بيبيّن فوراً. للتشغيل الفعلي على سيرفر:

```bash
npm run build
npm start
```

| المتغيّر | الافتراضي | شو بيعمل |
|---|---|---|
| `PORT` | `3400` | رقم المنفذ |
| `DATA_DIR` | `./data` | مكان ملف قاعدة البيانات `gapper.db` |
| `TRUST_PROXY` | فاضي | حطّه `1` إذا السيرفر ورا proxy (مثل Render) عشان الكوكي تنعلّم Secure |

## شو فيه

الشاشات العشرة من التصميم:

1. **الصفحة الرئيسية** `/`: الفكرة، الأقسام، المميزات، كيف بيشتغل، عن المشروع، والميزات المستقبلية.
2. **تسجيل الدخول وإنشاء حساب** `/login` و `/signup`، وفيه كمان **"جرّب كضيف"** بدون حساب (الملف اقترح تجربة بدون حسابات بالبداية). الضيف بيقدر يحوّل حسابه لحساب حقيقي من الإعدادات وبيضل تقدمه محفوظ.
3. **لوحة التحكم** `/dashboard`: إحصائيات، "كمّل التعلم"، المهارات الجاية، الفصل الحالي، المحفوظات، وآخر اللي شفته. بتقدر تغيّر سنتك وفصلك من الزر اللي فوق.
4. **خريطة المسار** `/roadmap`: السنوات الأربعة، كل سنة فيها فصلين، مع حالة كل مهارة والمتطلبات السابقة، وعلامة "إنت هون".
5. **تفاصيل المهارة** `/skills/:slug`: نظرة عامة (ليش مهمة، إيمتى، كيف تعرف إنك أتقنتها)، خطوات التعلم بصناديق تأشير، مهمة عملية مع مكان تكتب فيه تأمّلك، والمصادر.
6. **التقدم** `/progress`: نسبة كلية، تقدم كل فصل، تقدم كل قسم، وآخر نشاط.
7. **مكتبة المهارات** `/library`: بحث وفلترة حسب القسم والمستوى.
8. **المصادر** `/resources`: 50 مصدر (47 خارجي و3 قوالب جاهزة للطباعة) مع فلترة حسب النوع.
9. **الجوال**: كل الصفحات بتشتغل على الجوال، مع شريط تنقّل تحت.
10. **صفحة نهاية الرحلة** `/journey`: الرسالة التحفيزية وإحصائياتك والميزات المستقبلية.

وكمان: صفحة **الإعدادات** (الملف الشخصي، كلمة السر، إرسال ملاحظات، الخصوصية، حذف الحساب) وصفحة **البداية** اللي بتسأل الطالب عن تخصصه وسنته.

## اللغتين (عربي وإنجليزي)

الموقع كله بيشتغل بالعربي (من اليمين لليسار) وبالإنجليزي، مع زر تبديل فوق بكل الصفحات وقسم "اللغة" بالإعدادات. أول مرة بيختار اللغة حسب لغة المتصفح، وبعدها بيتذكّر اختيار الطالب.

- **نصوص الواجهة**: كلها بملف واحد `client/src/i18n.jsx`، وكل مفتاح فيه النسخة الإنجليزية والعربية جنب بعض. فيه كمان صيغ الجمع العربية (مهارة واحدة، مهارتان، 3 مهارات، 11 مهارة).
- **محتوى المهارات والمصادر**: الإنجليزي بـ `server/content.js`، والعربي بـ `server/content.ar.js` بنفس الـ slug. لازم عدد الخطوات وبنود المهمة العملية وعلامات الإتقان يكون نفسه باللغتين، وإلا السيرفر بيطبع تحذير وبيعرض الإنجليزي لهديك المهارة.
- **رسائل الأخطاء من السيرفر**: بـ `server/messages.js`. الواجهة بتبعت لغتها بالهيدر `X-Lang`.
- البحث بيدوّر باللغتين، وبيتجاهل التشكيل وفروق الهمزات والتاء المربوطة و"ال" التعريف.
- القوالب الجاهزة إلها نسخ عربية (`*-ar.html`). أغلب المصادر الخارجية بالإنجليزي، والواجهة بتنبّه لهالشي.

## هيكل المشروع

```
server/
  index.js     السيرفر (Express 5)، وبوضع التطوير بيشغّل Vite جوّاه
  db.js        قاعدة البيانات (node:sqlite) والجداول ومزامنة المحتوى
  auth.js      تشفير كلمات السر (scrypt)، الجلسات، الحماية
  api.js       كل الـ API
  content.js   المحتوى بالإنجليزي: 5 أقسام، 35 مهارة، مسارين (CS و CE)، 50 مصدر
  content.ar.js  ترجمة المحتوى للعربي
  i18n.js      اختيار لغة الرد والبحث باللغتين
  messages.js  رسائل الأخطاء بالعربي والإنجليزي
client/
  src/i18n.jsx     نصوص الواجهة باللغتين وزر التبديل
  src/pages/       الصفحات
  src/components/  المكونات المشتركة والرسومات
  src/styles.css   كل التنسيقات
  public/templates/  قوالب للطباعة (Cornell، مخطط أسبوعي، README) بالعربي والإنجليزي
```

## الاستضافة (Render)

ملف `render.yaml` بيجهّز خدمة مجانية على Render بفرانكفورت: بيبني الواجهة (`npm run build`) وبيشغّل السيرفر.

- **الخطة المجانية بتنام** بعد ربع ساعة بدون زيارات، وأول فتحة بعدها بتاخد حوالي دقيقة.
- **قرص Render المجاني مؤقت**: بدون قاعدة خارجية، كل الحسابات والتقدم بينمسحوا لما السيرفر ينام أو يتحدّث. عشان تنحفظ:
  1. اعمل قاعدة مجانية على [Turso](https://turso.tech) وخذ منها الرابط (`libsql://...`) والـ Token.
  2. بـ Render: الخدمة ← Environment ← حط `TURSO_DATABASE_URL` و `TURSO_AUTH_TOKEN` ← Save.
  3. السيرفر بيعيد التشغيل لحاله وبيصير يحفظ كل اشي بـ Turso.
- لتجربة مكتبة Turso على جهازك بدون نت: `DB_DRIVER=libsql npm start`.

## تعديل المحتوى (لصاحب دور المحتوى)

كل المهارات والمسارات والمصادر موجودة بملف واحد: **`server/content.js`**. عدّل عليه وأعد تشغيل السيرفر، والمحتوى بيتحدّث لحاله بدون ما يمسح حسابات الطلاب أو تقدمهم. إذا كتبت اسم مهارة غلط بالمسار أو بالمتطلبات، السيرفر بيرفض يشتغل وبيحكيلك وين الغلط.

- مهارة جديدة: زيدها على مصفوفة `skills`، وبعدين حط الـ `slug` تبعها بالمسار جوّا `roadmaps` تحت المفتاح `"سنة.فصل"` (مثلاً `'2.1'`).
- الأيقونات من [Lucide](https://lucide.dev/icons). إذا استعملت أيقونة جديدة، لازم تضيفها كمان بـ `client/src/icons.jsx`.
- المسار **مبدئي**، ومكتوب هيك بالواجهة، وبدّه مراجعة مع طلاب وخبراء مثل ما بيقول الملف.

## الأمان

- كلمات السر مشفّرة بـ scrypt، والجلسة كوكي `HttpOnly` و `SameSite=Lax`، وبقاعدة البيانات بس بصمة (hash) التوكن.
- أي طلب بيغيّر بيانات لازم يكون معه الهيدر `X-Gapper: 1`. هاد بيمنع طلبات مزوّرة من مواقع تانية (CSRF).
- في حد لعدد محاولات تسجيل الدخول وإنشاء الحساب، وتحقق من كل المدخلات على السيرفر.

## API باختصار

| الطلب | الوظيفة |
|---|---|
| `POST /api/auth/register` و `login` و `guest` و `logout` و `upgrade` و `password` | الحسابات |
| `GET /api/auth/me` و `PATCH /api/me` و `DELETE /api/me` | الملف الشخصي |
| `GET /api/meta` | الأقسام والتخصصات والسنوات |
| `GET /api/skills?q=&category=&level=` و `GET /api/skills/:slug` | المهارات |
| `PUT /api/progress/:slug` | تحديث الحالة والخطوات والتأمّل |
| `GET /api/progress` و `GET /api/dashboard` و `GET /api/roadmap?program=` | الملخصات |
| `PUT/DELETE /api/bookmarks/:slug` | حفظ مهارة |
| `GET /api/resources` و `POST /api/feedback` | المصادر والملاحظات |

الملاحظات اللي بيبعتها الطلاب بتنحفظ بجدول `feedback` بقاعدة البيانات.
